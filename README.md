# 📄 AI Resume Builder

An AI-powered resume builder that helps users create professional,
ATS-friendly resumes from their personal information.

The application uses Python, Streamlit and Ollama for local AI-powered
resume generation.

---

## 🚀 Features

- 🤖 AI-powered resume generation
- 📄 ATS-friendly resume format
- 🎯 ATS compatibility analysis
- 🔑 Matching keyword detection
- ⚠️ Missing keyword detection
- 💡 Resume improvement suggestions
- 📝 Multiple projects
- 💼 Multiple internships/experiences
- 🎨 Multiple resume templates
- 💾 Save resume profiles
- 📂 Load saved profiles
- 🗑️ Delete profiles
- 📘 Download DOCX
- 📕 Download PDF
- 🏠 Professional dashboard
- 🔐 Local AI processing with Ollama

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- python-docx
- ReportLab
